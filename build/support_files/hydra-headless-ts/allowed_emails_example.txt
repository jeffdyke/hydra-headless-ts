# Per-resource allowlist for `example` -- the one named, gated mariadb-mcp
# instance carried for local dev (docker-compose.mariadb-mcp.dev.yml's
# mariadb-mcp-example service, at /db-tools/example). Point its DB_HOST at
# whatever database you have locally; it's a template, not a specific node.
# Checked *in addition to* allowed_emails.txt, never instead of it -- an address
# must pass both, so removing someone from the global list revokes every
# resource.
#
# If this file is missing or unreadable the app denies EVERYONE rather than
# falling back to the global list (isEmailAllowedForResource in
# src/fp/services/emailAllowlist.ts returns false on a null list).
#
# Format: bare lines are domains, lines containing @ are individual addresses,
# # comments and blank lines ignored.
#
